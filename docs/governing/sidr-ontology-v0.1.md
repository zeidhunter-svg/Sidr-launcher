# Онтология Sidr v0.1

> **Статус: черновик для обсуждения (владелец + агент, 2026-11-07). Не решение, не спека.**
> Понятия и аксиомы — гипотезы, пока не получат проверку (тест) или честное `<нет>`, как строки
> [доктринальной матрицы](sidr-doctrine-matrix-v1.0.md). Опора: ADR «2026-11-07 — Два принципа агентной
> ОС» (`ai-context/decisions.md`).

## 0. Формула

**Sidr — операционная система открытого мира:** открытая многослойная система, устроенная по законам
реального мира (математики, физики, информатики); закрытая в границах каждого слоя.
Короткая форма: *открытая в возможностях, закрытая в границах.*

## 1. Понятия

| Понятие | Смысл | Уже в коде |
|---|---|---|
| **Субъект** | человек-принципал; источник воли и согласия; единственный, кто свободно переходит слои | `PrincipalId.USER`, `ValueOrigin.SaidBy` |
| **Агент** | действует по поручению субъекта, в его пределах; сам границ не пересекает | `AgentSession`, `AgentExecutor` |
| **Слой (сфера)** | область со своей функцией, источником и правилами | `ToolLevel`; окружения (идеи H, L); устройства |
| **Граница-мембрана** | закрыта по умолчанию; пропускает только названное | фильтр выдачи `OFFERED_LEVELS`; `OutboundContextPolicy.ALLOWED` |
| **Видимость** | что слой знает о другом (что он есть, что умеет) | описания выдачи (видимо) vs мир пользователя (невидимо модели, D1) |
| **Проницаемость** | что и в какую сторону проходит через границу | allow-list исходящего; исход привязки не идёт к модели |
| **Закон ядра** | правила, одинаковые во всех слоях; ядро — закон, не правитель | один путь к миру (`ToolExecutor`), `requiresConsent`, трасса |
| **Способность** | действие, доступное в слое | `ToolDescriptor` |
| **Наблюдение** | знание о мире; незнание — «неизвестно», не «ложно» (открытый мир) | `ObservedFact`, `ToolResult.HandedOff` |
| **Действие** | обратимое / необратимое; внутреннее / внешнее | `ToolDurability`, `ToolEffect`, компенсации |
| **След** | память о сделанном — для ответственности и отката | `TraceEvent` |

## 2. Отношения

- Слой ↔ слой: **видимость** и **проницаемость** — два разных отношения; видимый слой может быть
  непроницаемым.
- Субъект → слой: входит и выходит; вход/выход может требовать подтверждения личности (окно полного
  доступа; «Детское» — выход только родителю).
- Агент → слой: действует только там, куда допущен субъектом; переход границы — через согласие.
- Закон ядра → все слои: одинаков везде; число слоёв не меняет числа законов.

## 3. Аксиомы (кандидаты)

| # | Аксиома | Проверка |
|---|---|---|
| A1 | Нет слоя, невидимого своему хозяину: субъекту видно всё о нём самом — что агент знает, сделал, что ушло наружу | `<нет>` |
| A2 | Закон ядра одинаков во всех слоях; новый слой и новая способность не добавляют закона | частично: гварды — свёртки над федерацией (A1″ 3b: 11 инструментов — 0 веток) |
| A3 | Граница закрыта по умолчанию; открытие — решение, а не умолчание | фильтр-allow-list уровней (F3a-A) |
| A4 | Агент не пересекает границу без субъекта; необратимое — только с согласием | `AgentExecutorTest` (согласие), `DOC-ADL-1` |
| A5 | Разрешение расширяет охват, гейта не снимает | `DOC-HMA-5` (`<нет>`) |
| A6 | Отсутствие знания — неизвестность, не ложь | `<нет>` (находка A0.5 §6.3 — граница двух предположений) |
| A7 | Содержимое слоя — данные, не инструкции | `BridgePayloadGuardTest` (частично: в обратную сторону) |

## 4. Основание

- Реальный мир: сферы (океан, атмосфера, космос) не преступают границ, но обмениваются через поверхность —
  граница-мембрана, не стена.
- Созвучие с доктриной (восемь исламских принципов): «два моря встречаются; между ними преграда (*барзах*),
  которую они не преступают» (55:19–20); весы (*мизан*) и мера (55:7–9; `DOC-MZN`); «каждый плывёт по
  своей орбите» (36:40). Явность этой опоры — решение владельца.

## 5. Ограничения метода

- Аналогия вдохновляет, но не доказывает: аксиома живёт, только получив проверку.
- Слой рождается из реальной разницы (доверие, видимость, обратимость), не из эстетики.
- «Закрыта в границах слоя» ≠ «внутри слоя без ограничений»: закон ядра действует и внутри.

## 6. Открытые вопросы

- Слои: исчерпывающий перечень или открытый (как способности)?
- Невидимые слои: какие и для кого (модель, другие люди, другие агенты)?
- Несколько субъектов (Сидр-сеть): чья воля, когда слои двух людей соприкасаются (агент↔агент)?
- Перевод аксиом в строки доктринальной матрицы — через change-control (Master Plan §5).
