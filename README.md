# Sidr-louncher

AI Launcher нового типа, где ИИ является не отдельным чат-ботом, а центральным интерфейсом всей системы.

Что это будеть

Пользователь вместо привычного набора иконок взаимодействует с телефоном через единое поле ввода:

«Открой Telegram»

«Включи Wi-Fi»

«Позвони Ахмаду»

«Что у меня сегодня по расписанию?»


ИИ преобразует запрос в структурированный Intent и выполняет действие через Android Framework.


---

Основные особенности

1. Гибридный AI (главная особенность)

Лаунчер автоматически определяет возможности устройства:

Слабые устройства (<6 ГБ RAM)

работают через облачные модели (OpenAI, Groq, Anthropic);

минимальная нагрузка на смартфон.


Мощные устройства (8+ ГБ RAM + NNAPI/NPU)

запускают локальную модель (Gemma, Phi-3 и т.д.);

могут работать без интернета;

выше приватность.


Это похоже на сочетание:

Pixel AI + Gemini Nano;

Rabbit OS;

Nothing Essential Space;

Microsoft Recall (по идее, не по реализации).



---

2. Intent-first архитектура

LLM никогда не управляет телефоном напрямую.

Схема:

Пользователь
     ↓
LLM
     ↓
JSON Intent
     ↓
Intent Executor
     ↓
Android API

То есть ИИ выступает как "переводчик" человеческой речи в команды Android.

Это безопаснее и предсказуемее, чем позволять модели выполнять произвольный код.


---

3. Минималистичный интерфейс

Главный экран фактически состоит из:

строки ввода;

кнопки голоса;

области ответа;

динамических карточек/ярлыков.


То есть интерфейс напоминает смесь:

Spotlight (iPhone),

Raycast,

Arc Search,

Rabbit R1.



---

4. Адаптация под контекст

ИИ может предлагать действия:

Утром:

Карты;

Погода;

Будильник.


Вечером:

YouTube;

Spotify;

Домашний Wi-Fi.


На работе:

Slack;

Gmail.



---

5. Независимость от конкретной модели

Архитектура построена вокруг интерфейса:

AiEngine

Поэтому можно заменить:

OpenAI → Groq;

Groq → Claude;

Gemma → Phi-3;

ONNX → MediaTek NeuroPilot;


без переписывания остального приложения.


---

Чем отличается от обычных лаунчеров?

Обычный лаунчер:

Экран → иконки → пользователь ищет приложение

Наш:

Пользователь → ИИ → действие

То есть пользователь взаимодействует не с приложениями, а с намерениями.


---

Самая интересная особенность

Самая сильная идея  — автоматический переход между облачной и локальной моделью в зависимости от железа телефона.

Большинство AI-лаунчеров сегодня либо:

полностью облачные;

либо требуют только флагманские устройства.


Здесь одна и та же архитектура сможет работать и на бюджетном Samsung A13, и на Galaxy S25 Ultra, просто меняя способ выполнения AI. Это делает продукт гораздо более массовым.
