Soft classic grey

Neutral, timeless, low-drama. The accent — a soft pewter — appears only on the input prompt/caret, the next-prayer hint, and focus. Selection is press-invert (light-on-dark), so the active chip reads without introducing colour. Corners softened to 10dp; the terminal > and block caret stay.
